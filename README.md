# INTEGRAL — 양손으로 빚는 3D 도자기

웹캠에서 양손을 추적하고, 양손 검지 끝 사이 거리로 새로 쌓이는 도자기 층의 폭을 조절하는 p5.js 프로젝트입니다. 양손을 벌리면 넓게, 모으면 좁게 쌓입니다. 도자기는 무광 점토 재질이며, 적층 중에는 자동 회전합니다.

이 ZIP은 2026-10-12에 배포한 최신 버전의 실행 코드입니다. p5.js, MediaPipe, WASM, 손 인식 모델을 모두 포함하므로 실행할 때 CDN에서 별도로 다운로드하지 않습니다.

## 2. 실행 방법

### GitHub Pages 자동 배포

이 저장소에는 `.github/workflows/deploy-pages.yml`이 포함되어 있습니다. GitHub 저장소의 **Settings → Pages → Build and deployment → Source**에서 **GitHub Actions**를 선택하면 `main` 브랜치에 코드를 올릴 때 자동으로 배포합니다.

최초 배포가 성공한 후의 실행 주소는 `https://53nu.github.io/CA_P4/`입니다. Actions 탭에서 **Deploy pottery to GitHub Pages** 워크플로의 성공 여부를 확인하세요. 이 주소는 배포 완료 전에는 열리지 않을 수 있습니다.

화면은 HTTPS로 제공되므로 팀원이 별도 서버를 켜지 않고 카메라 권한을 허용해 사용할 수 있습니다. 카메라 영상은 방문자의 기기에서 처리합니다.


### 방법 A: VS Code Live Server

1. ZIP을 풀고 `integral-pottery` 폴더를 VS Code로 엽니다.
2. Live Server 확장이 설치되어 있다면 `index.html`을 오른쪽 클릭하고 **Open with Live Server**를 선택합니다.
3. 열린 브라우저에서 **카메라 켜기 / 다시 연결**을 누르고 카메라 권한을 허용합니다.
4. 양손을 카메라에 보여줍니다.

### 방법 B: Python

Python 3가 설치되어 있다면 `index.html`이 있는 폴더에서 실행합니다.

```bash
python3 -m http.server 8000
```

Windows에서 `python3` 명령이 없다면 `py -m http.server 8000` 또는 `python -m http.server 8000`을 사용합니다.

브라우저 주소는 `http://localhost:8000/`입니다. 종료하려면 서버를 실행한 터미널에서 `Ctrl+C`를 누릅니다.

### 팀원이 서버를 직접 켜지 않고 이용하려면

이 폴더 전체를 HTTPS 정적 웹 호스팅에 올린 뒤 실행 주소를 공유하면 됩니다. 별도의 백엔드나 빌드 과정, npm 설치는 필요하지 않습니다. WASM 파일을 포함한 `vendor/` 폴더를 함께 올려야 합니다.

파일을 더블클릭해서 `file://` 주소로 열면 모듈·WASM 로딩이 제한될 수 있습니다. localhost 또는 HTTPS에서 실행하세요. 웹캠은 **페이지를 열고 있는 사람의 기기**에서 사용합니다. 영상은 브라우저 안에서 처리하며 이 코드에는 영상을 서버에 업로드하는 기능이 없습니다.

## 3. 조작법

| 동작 | 결과 |
| --- | --- |
| 양손 검지 끝을 벌리기 | 새 층의 반지름 증가 |
| 양손 검지 끝을 모으기 | 새 층의 반지름 감소 |
| 양손을 위·아래로 이동 | 새 층의 표면 굴곡 강도 변화 |
| 한 손 또는 양손을 화면 밖으로 이동 | 적층과 자동 회전 중단 |
| 도자기 영역을 클릭하고 드래그 | 도자기 수동 회전 |
| 도자기 영역에서 마우스 휠 | 확대·축소 |
| `Space` 또는 PAUSE 버튼 | 적층 일시정지·재개 |
| `R` 또는 RESET 버튼 | 도자기와 회전 상태 초기화 |

양손 사이에는 희미한 흰색 선이 표시됩니다. 이 선은 도자기보다 먼저 그려져 도자기 뒤에 가려집니다. 거리 숫자와 기존 HAND POSITION / LIVE 패널은 표시하지 않습니다.

## 4. 프로그램이 동작하는 순서

1. `index.html`이 로컬 p5.js와 `sketch.js`를 불러옵니다.
2. `setup()`이 전체 화면 캔버스, 도자기용 WebGL 버퍼, 손 마스크용 버퍼와 UI를 만듭니다.
3. 사용자가 카메라 버튼을 누르면 `startCamera()`가 영상 권한을 요청합니다. 마이크는 요청하지 않습니다.
4. 카메라 프레임이 준비되면 MediaPipe 모듈·WASM·모델을 로드합니다. GPU 초기화가 실패하면 CPU로 다시 시도합니다.
5. `draw()`가 프레임마다 손 인식, 손 마스킹, 연결선, 자동 회전, 도자기 렌더링, UI 갱신을 처리합니다.
6. 양손이 인식되고 일시정지 상태가 아니면 최소 100ms마다 새 층을 추가합니다.

## 5. 양손 사이 거리 계산

MediaPipe에서 손마다 21개의 랜드마크를 얻습니다. **8번은 검지 끝**입니다. `numHands: 2`로 최대 두 손을 추적합니다.

좌표는 카메라 영상의 크기와 화면 비율을 고려해 화면 좌표로 변환하고, 카메라 미리보기와 일치하도록 좌우를 반전합니다. 손 인식 결과의 순서가 바뀌면 이전 좌표와 가까운 조합을 선택해 손이 갑자기 바뀌는 현상을 줄입니다.

검지 끝 좌표가 `(x1, y1)`, `(x2, y2)`이면 거리는 다음과 같습니다.

```javascript
const distance = Math.hypot(x2 - x1, y2 - y1);
```

수평 거리만 측정하지 않고 대각선 거리도 반영합니다. 이 값의 단위는 화면상의 픽셀이며 실제 손 사이 거리를 cm로 측정하는 것은 아닙니다.

`getMotionData()`에서 거리를 반지름으로 바꿉니다.

```javascript
const radius = map(distance, 0, width * 0.65, 30, CFG.maxRadius, true);
```

손 사이 거리가 0에 가까우면 목표 반지름은 30px, 화면 너비의 65% 이상이면 최대 반지름 150px이 됩니다. 두 손을 함께 좌우로 옮겨도 서로 간격이 같으면 목표 반지름은 같습니다.

손 좌표는 `handSmoothing: 0.18`로 부드럽게 보간하고, 실제 새 층의 반지름도 목표 반지름을 향해 `lerp(..., 0.12)`로 보간합니다. 그래서 손을 갑자기 벌려도 형태가 바로 계단처럼 꺾이지 않습니다.

## 6. 적층 기준과 표면 굴곡

높이는 손 높이로 결정하지 않습니다. **양손이 인식된 시간을 따라 아래에서 위로 쌓습니다.** 이미 만들어진 층의 반지름은 유지하고 새 층만 손 간격에 따라 달라집니다.

| 설정 | 현재 값 | 의미 |
| --- | --- | --- |
| `layerHeight` | 3 | 한 층의 기본 높이 |
| `buildInterval` | 100 | 새 층 사이 최소 간격, 밀리초 |
| `maxHeight` | 430 | 높이 상한 |
| 실제 최대 층수 | 143 | 430을 3으로 나눈 값의 내림 |
| 실제 최대 높이 | 429 | 143층 × 3px |

100ms는 최소 간격입니다. 실제 적층 속도는 렌더링·인식 프레임 속도에 따라 더 느려질 수 있습니다. 손이 사라진 동안의 층을 나중에 한꺼번에 추가하지 않습니다. 양손을 다시 보여주면 새 간격부터 시작합니다.

양손 검지 끝의 평균 Y좌표로 표면 굴곡 배율을 구합니다.

```javascript
smoothHandY = (smoothTips[0].y + smoothTips[1].y) * 0.5;
const relief = map(smoothHandY, height * 0.15, height * 0.8, 1.4, 0.55, true);
```

손을 위에 둘수록 굴곡 배율이 커지고, 아래에 둘수록 작아집니다. 이 값은 각 층의 `thickness`에 저장되어 층 사이의 돌출된 결을 조절합니다. 기본 적층 높이 3px는 바뀌지 않습니다.

## 7. 손 마스킹과 3D 도자기

`generateHandMask()`가 양손 각각의 손바닥 다각형과 손가락 선분을 하나의 마스크에 그립니다. `drawMaskedHandBackground()`는 마스크 안의 카메라 영상 밝기를 작은 점의 크기로 바꿔 손만 하프톤으로 표시합니다.

이 마스크는 관절 좌표로 근사한 형태입니다. 손의 실제 윤곽을 픽셀 단위로 정확히 분리하는 모델은 아닙니다.

`potteryLayers`에는 층마다 반지름, 높이, 굴곡, 난수 시드가 저장됩니다. `drawPottery3D()`는 각 층의 원형 단면을 삼각형으로 연결해 외벽과 내벽을 만들고, 위쪽 테두리와 속이 빈 입구도 그립니다. `ringRadius()`와 `surfacePoint()`가 작은 불규칙성과 점토 층의 굴곡을 더합니다.

재질은 `ambientMaterial()`로 설정한 무광 점토입니다. 손 영상과 도자기는 서로 다른 버퍼에서 그린 뒤 전체 화면에 합칩니다.

## 8. 자동 회전과 수동 회전

`updateAutomaticRotation()`이 프레임 시간 `deltaTime`에 비례해 Y축 회전각을 늘립니다.

```javascript
rotationY += CFG.autoRotationSpeed * Math.min(Math.max(deltaTime, 0), 100) / 1000;
```

현재 `autoRotationSpeed`는 **0.35 rad/s**, 약 **20°/s**입니다. 프레임 속도가 달라도 비슷한 속도로 회전하도록 했고, 탭을 오래 벗어났다가 돌아올 때 갑자기 크게 회전하지 않도록 한 프레임의 시간 반영을 100ms로 제한합니다.

다음 조건을 모두 만족할 때 자동 회전합니다.

- 양손이 인식됨
- 적층이 일시정지되지 않음
- 도자기가 한 층 이상 만들어짐
- 최대 높이에 도달하지 않음
- 마우스나 터치로 도자기를 드래그하는 중이 아님

드래그하는 동안에는 수동 회전이 우선합니다. 드래그를 놓고 적층 조건이 유지되면 현재 각도에서 자동 회전을 이어갑니다.

## 10. 자주 바꾸는 값

`sketch.js` 위쪽의 `CFG`를 수정하면 됩니다.

| 원하는 변경 | 수정할 값 |
| --- | --- |
| 더 천천히 쌓기 | `buildInterval` 증가: 예를 들어 200 |
| 더 빠르게 쌓기 | `buildInterval` 감소: 예를 들어 60 |
| 더 높게 만들기 | `maxHeight` 증가 |
| 더 넓게 만들기 | `maxRadius` 증가 |
| 자동 회전 빠르게 / 느리게 | `autoRotationSpeed` 증가 / 감소 |
| 자동 회전 끄기 | `autoRotationSpeed: 0` |
| 손 움직임에 빨리 반응 | `handSmoothing` 증가, 1 이하 |
| 손 움직임을 더 부드럽게 | `handSmoothing` 감소, 0보다 크게 |
| 도자기 원형 단면을 더 매끈하게 | `segments` 증가; 연산량도 증가 |
| 손 하프톤 점을 더 촘촘하게 | `cellSize` 감소; 연산량도 증가 |

최소 반지름 30px와 거리 변환 범위 `width * 0.65`는 `getMotionData()` 안에서 바꿉니다. 흰색 연결선의 밝기는 `drawMovementGuides()`의 `stroke(245,245,240,55)`에서 마지막 값 55를 바꿉니다. 0은 투명, 255는 불투명입니다.

## 11. 문제가 생길 때

| 증상 | 확인할 내용 |
| --- | --- |
| 카메라 권한 오류 | 브라우저의 사이트 카메라 권한과 운영체제의 브라우저 카메라 권한 확인 |
| 미리보기 안에서 카메라가 막힘 | 실행 주소를 Safari 또는 Chrome에서 직접 열기 |
| 카메라가 사용 중이라는 오류 | 다른 영상통화·촬영 앱을 닫고 다시 연결 |
| 모듈·WASM·모델 로딩 실패 | `vendor/` 누락 여부, localhost/HTTPS 실행 여부 확인 |
| 영상은 보이지만 도자기가 안 쌓임 | 양손 모두 카메라에 들어오는지, 일시정지 상태인지, 최대 높이에 도달했는지 확인 |
| 손이 잘 인식되지 않음 | 밝은 환경에서 손 전체를 보여주고, 두 손이 서로 많이 겹치지 않도록 하기 |

카메라 없이 렌더링을 점검할 때는 실행 주소 뒤에 `?demo=1`을 붙일 수 있습니다. 메뉴에는 표시하지 않는 개발용 모드이며, 샘플 도자기와 마우스 회전을 확인합니다. 실제 손 인식·적층은 실행하지 않습니다. 카메라 모드로 돌아갈 때는 `?demo=1`을 지웁니다.
